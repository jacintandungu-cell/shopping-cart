# 🛍️ Dynamic Shopping Cart App

A React-based shopping cart application built as part of a lab project to practice **state management**, **event handling**, and **conditional rendering** using the `useState` hook.  
This app includes a **dark mode toggle**, **category filters**, and **add-to-cart functionality** — all wrapped in a cheerful, presentable UI.

---

## ✨ Features
- 🌗 **Dark Mode Toggle**  
  Switch between light and dark themes with smooth transitions.

- 🛒 **Add to Cart**  
  Add items from the shopping list to your cart, with a live cart count badge.

- 🗂️ **Category Filter**  
  Filter items by category (Fruits 🍎, Vegetables 🥕, Dairy 🥛, Bakery 🍞).

- 🎀 **Adorable UI**  
  Pastel colors, rounded cards, hover effects, emojis, and animations for a delightful shopping experience.
